## Veille creations d'entreprises
API `recherche-entreprises.api.gouv.fr` (sans cle), departements des zones sauf le 54 (garde-fou en dur),
creations de moins de 180 jours, 3 pages par departement. Ecrit `veille-AAAA-MM-JJ.ndjson` dans
`/home/node/.n8n-files/agency/` sur le VPS (a recuperer puis `prospects.py add`). Secrets : aucun.
Lancer : activer, ou executer manuellement depuis l'interface n8n.

## Enrichissement presence en ligne
Entree (POST JSON) : `{"ndjson": "<lignes de prospects.ndjson>"}` ou `{"prospects": [...]}`, 60 max par appel
(champs lus : siren, cle, nom, nom_commercial, ville, dept). Le 54 est ignore.
Sortie : `{count, osm_interroge_ok, web_ok, web_bloque, ndjson}`. Chaque ligne du `ndjson` :
`siren`, `cle`, `source` precise, `verif_sources` (etat de chaque source), et seulement si prouve :
`site`, `telephone`, `signaux.pas_de_site=false`.
Regles : une etiquette trouvee est une preuve ; une absence ne produit rien. Jamais `gbp_absente`,
`reseaux_inactifs` ni `pas_de_site=true` : ils restent dans `a_verifier`.
Ingestion : `python3 agency/scripts/prospects.py add lot.ndjson` (ne remplace pas les champs deja remplis,
fusionne les signaux).

```bash
# Appel (apres activation du workflow) ; cle et ligne a adapter
curl -s -X POST https://n8n.clairargent.fr/webhook/agence-enrichissement-3f9a1c \
  -H 'Content-Type: application/json' \
  -d "$(python3 -c 'import json,sys;print(json.dumps({"ndjson":open("lot.ndjson").read()}))')" \
  | python3 -c 'import json,sys;sys.stdout.write(json.load(sys.stdin)["ndjson"])' > enrichi.ndjson
```

## Reprise apres redemarrage du conteneur
Les workflows vivent sur le VPS, pas dans le conteneur : un redemarrage ne les efface pas.
1. `n8n_health_check` doit repondre `ok`.
2. `n8n_list_workflows` : verifier la presence des deux noms ci-dessus (IDs du tableau).
3. Absent : recreer depuis `n8n/enrichissement-presence.json` (`n8n_create_workflow` avec ses `nodes`,
   `connections`, `settings`) ; la veille se recree depuis la description ci-dessus (planification + code).
4. `n8n_validate_workflow` jusqu'a 0 erreur. Verifier `active: false`.
5. Pour tester un workflow a webhook, `n8n_test_workflow` exige qu'il soit actif : l'activer, tester,
   **le desactiver aussitot** (`n8n_update_partial_workflow` `activateWorkflow` / `deactivateWorkflow`).
